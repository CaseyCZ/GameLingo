# Native combination experiment
No Tesseract. Android bundled ML Kit, iOS bundled ML Kit and Vision; synthetic 1280x720 fixtures, ten active zones, a separate overlap probe, moving and disappearing text. OCR emits actual native line boxes; shared offline scorer groups, deduplicates and assesses exact normalized text and bounding box IoU. Prefix sums are estimates for serial zone counts, not separate device benchmarks. Host SubLens preprocessing time is not mobile filter performance. Fallback on empty results only, no OCR truth used for selecting mode. Fixture translations are metadata, not actual translation or rendered TV output. No changes to production, no paid external API. Previous full benchmark source retained; CI on this experimental branch now targets the smaller combination test. Requires device validation, actual runtime tracking and TV rendering in a later experiment. Grouping inspiration: D3ATHLY/GameTranslator commit 5eb0ed4d5b1977fe03afb1d9509494768616a2d4 (AGPL-3.0), independently implemented. SubLens attribution unchanged.
