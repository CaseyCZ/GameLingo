# ML Kit OCR Lab
Isolated Android instrumentation benchmark; production GameLingo unchanged.
Same bundled Latin model as upstream Android build: com.google.mlkit:text-recognition:16.0.1. No internet permission requested; actual OCR via InputImage.fromBitmap and reusable TextRecognizer, not mocked.
72 existing reference frames (48 synthetic and 24 pinned GeekLink public images, see ocr-lab/ATTRIBUTION.md). Nine existing filters at 100%, four additional scales for raw and outline, five adaptive raw scales targeting median word bounding-box height (16,20,24,32,40 px, capped 0.75–2). 22 configurations, 1584 calls plus smoke. Adaptive probe is charged to latency; fixed scaling after filtering (different from desktop scale-before-filter), no claim of exact character size. Three output variants: raw, geometry heuristic, confidence >=0.60; score each independently. Host preprocessing not included in emulator timings; resize and probe included, postprocessing excluded. No TV or iOS latency claim, no translation or audio. Only public text and measurements uploaded, not source film images.
Official ML Kit examples: https://github.com/googlesamples/mlkit/tree/8cb8b8792b28568c59a8bf70cb7af94522ffa1f6 (Apache-2.0; no copied source). Adaptive scale concept inspired by https://github.com/TheJoeFin/Text-Grab/tree/f0345015dcabf572453568addfcecc64abfc1c16 (MIT; independent implementation). Existing SubLens filter remains attributed in ocr-lab.
