# Native OCR filter study

Compare raw pixels and existing SubLens filter on the same 24 cases, 48 native calls per engine. 12 new deterministic synthetic crops (two each: dark clean, bright, busy, colored, low contrast, small JPEG compressed) and 12 reused pinned public film ROIs (six each without/with watermark; scaled to fit 960x540). Public references have text truth only, not geometry truth. See ocr-lab/ATTRIBUTION.md; source frames are not uploaded. Alternate mode order by case to reduce warmup bias. Report exact normalized text, CER, paired wins/ties, synthetic exact geometry IoU >= .5, median OCR time and host filter overhead separately. Raw-first fallback only on no alphabetic words, evaluated retrospectively from actual paired readings, not a live policy. No Tesseract, external AI API, live translation, or physical device timing. Old ten-zone experiment remains in git history; CI targets this follow-up. No production modifications.
