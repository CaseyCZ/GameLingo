## Důležité: co z výsledku nevyplývá

- Žádný spolehlivý počet mrtvých tříd ani velikost úspory APK/IPA; není rozbalen aktuální build, nepouštěl se lint, linker map, Gradle dependency report nebo runtime coverage. Přímá cesta LgDevModeView.kt nebyla nalezena (404); callsites jsou ale doložené, umístění implementace ještě ověřit.
- Staré publish workflow se na audit branch push nespouští dle jejich triggerů; manuální dispatch nepoužívat. Neprověřován stav všech historických releases a assets mimo větev. Neprovádět release cleanup.
- Není prokázáno, že PlayCaption funkce nemají uživatele. Zachovat AGPL a notices, konzole Xbox/PS4/PS5, HDMI, čtyři oblasti, profily, QR a port fallback, podporované jazyky, offline mobilní překlad a TV OCR/online. Bez nové designové změny.

## Akceptační podmínky navrhovaného úklidu (bod 6–8)

1. Inventář všech tří výsledných balíčků podle stejné revize: zip entries a velikosti, ABI/native knihovny, generated manifest/Info.plist, resources, assety LG/Samsung, JPG a staré viditelné texty. Porovnání stejných variant před/po. Rozlišit velikost distribučního souboru a instalace.
2. Android Gradle resolved runtime dependencies, lint a resource references; iOS Xcode target membership/linker map, reference scan včetně C callbacků. U kandidátů prokázat nulové runtime/build/test/migration consumers nebo schválené vyřazení celé funkce.
3. Po schválení samostatný commit pro každou logickou skupinu; full CI a zařízení pro konzole, overlay, QR, čtyři oblasti, profil migration, signed LAN transport. Ověřit TV DEX absence a mobilní presence offline translatoru.
4. Žádné automatické mazání historických releases/branches nebo přepis tagů. Dokumentovat před/po, rollback a licenční evidence.

Bod 4 dokončen jako cílený statický inventář. Není zatím schválen žádný removal, aplikace nezměněna. Další bod 5 — sjednocení dokumentace všech tří platforem a skutečného stavu v0.5, včetně security/privacy, licence, testovacích omezení a release gates.
