# Xbox and PlayStation icon attribution

The native Android and Google TV user interface embeds two **Font Awesome Free 6.7.2** brand icons:

- Xbox icon: https://github.com/FortAwesome/Font-Awesome/blob/6.x/svgs/brands/xbox.svg
- PlayStation icon: https://github.com/FortAwesome/Font-Awesome/blob/6.x/svgs/brands/playstation.svg
