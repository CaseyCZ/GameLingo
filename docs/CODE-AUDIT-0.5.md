## Potvrzené implementační vlastnosti (statická evidence)

- iOS oba konzolové starty používají stejný makeFrameReceiver a dva latest-frame mailboxes; stop invaliduje revize, ruší tasks, zavírá mailbox, clear TV a zastaví Remote Play. P1.9 guardy před úspěšným renderem kontrolují relaci, aktuální reading revision, jazyky a cancel; P2.4 glossary až po success, historie za guardem. Neřeší však CODE-01 ani skutečnou síťovou latenci.
- Android/TV generované patche zachovávají provider fallback, SQLite per engine/language, explicit failure, omezené image sampling, context generation pro yellow. TV build policy vynechá pouze offline ML Kit Translation; source audit, Gradle a DEX check prošly. Zachovat direct TV online OCR i telefonní receiver. Nelze z toho odvodit plnou paritu geometry/story.
- TV přijímač podporuje HMAC, signed replay checks, Keystore, per-phone revoke a explicitní legacy. Zbývající bezpečnostní audit (plaintext bootstrap, oddělený account transfer, story ACK, trust boundary, logs/privacy) je bod 3, ne zde potvrzená bezpečnost transportu.
- P2.3 historie opt-in/RAM-only, P2.4 slovník pro explicitně vybranou hru; Android story nezapisuje historii ani nepoužívá glossary. To je zdokumentované funkční omezení, ne nový přislíbený feature.
- P1.9 Android dialogue snapshot je na translation boundary, nikoliv všechny OCR callbacks; A→B→A blue ROI a staré story kontexty vyžadují regresní test. Model language catalog zachovat cs/sk UI Android vs cs/en/sk iOS, source/target katalog beze změny; UI parita neznamená pixelovou shodu.
