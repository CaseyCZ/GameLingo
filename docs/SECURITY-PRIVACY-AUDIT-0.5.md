# GameLingo 0.5 — zabezpečení a soukromí (bod 3)

Datum 2026-11-24. Statický cílený audit revize `973d5540beae07fff3da1b29cdf2af2e0976ff7a` na `feature/audit-0.5`; poslední nativní CI 45384321662 (šest jobů PASS na aplikační revizi f34348b1). Kontrolovány níže uvedené Swift/Kotlin soubory a generátor TV/Android. Nejde o penetrační test, kontrolu všech tranzitivních závislostí, skutečně vygenerovaného APK/IPA ani fyzického zařízení. Žádné aplikační změny, žádný release. TLS/nové kryptografické schéma neimplementovat bez samostatného rozhodnutí.

## Potvrzené ochrany a hranice

- TV 180 s PIN, max pět platných pokusů, 32 náhodných bajtů pro klíč; Keystore AES-GCM/AAD per phone ID, replay high-water a individuální revoke. Legacy výchozí off dle P0.1; výjimka PCS1 account transfer SEC-02. iOS Keychain AfterFirstUnlockThisDeviceOnly pro receiver a Xbox token (XboxAuthorization.swift 41–71); Android sender Keystore AES-GCM. Nepřisuzovat těmto vlastnostem šifrování UDP.
- P0.2 podepsané časové údaje a sekvence, PONG nonce, P0.4 oddělení zdrojů; HW test replay, persistence a revoke čeká.
- iOS Vision / Android ML Kit OCR jsou lokální OCR cesty dle předchozího code auditu. Posuzovaný iOS online translator přijímá text, nikoli snímek. Úplná absence screenshot uploadu, telemetrie SDK či jiných odchozích dat není prokázána. TV samostatný offline překlad ML Kit odstraněn, mobilní Android zachován; OCR a online TV nezměněny.
- TranslationHistory.swift 3–23 a GameLingoTranslationHistory.kt 3–15: historie opt-in v paměti, vypnutí ji vymaže; cache je jiný subsystém.
- Neověřeno: generated manifests/Info.plist/ATS, exported services/receivers, overlay/media projection a local-network permission denial, dependency CVE/SBOM, signing provenance, Android PS/Xbox credential persistence, skutečná síťová komunikace, SDK telemetry, WebRTC/Chiaki native trust and logging. Neoznačovat za PASS. Nepřidávat oprávnění ani telemetry. Android TV offline translator znovu nepřidávat.

## Akceptační testy pro bod 7/8

1. Na izolované vlastní LAN a syntetických účtech: ověřit, co putuje v pairing a game data; špatný/expirující PIN, pět pokusů, replay, změna pořadí, reboot, individuální revoke, legacy-off/on, port fallback 41989–41993. Neprovádět capture cizích účtů.
2. PCS1 account import: zjistit dostupnost a obsah testovacím dummy tokenem, včetně odmítnutého PIN a neověřeného response; vyřešit SEC-02 před distribucí.
3. Mock ACK a Xbox session response/redirect na nepovolený host: žádné důvěryhodné potvrzení a žádný citlivý header mimo schválené endpointy po opravách.
4. Originál, překlad, IP, dummy credentials/PIN/SDP canary: kontrola souborů, exportu logu, cache, historie, záloh, odhlášení a revokace; po purge ověřit i SQLite sidecars. Vše pouze testovací údaje.
5. Zachytit odchozí destinace při OCR, online překladu, cache hit, offline mobilním překladu a vypnuté historii; odmítnutí overlay/local-network oprávnění, přepnutí HDMI, ukončení relace a žádný tichý pokračující OCR/network request.
6. Před release kontrola skutečného APK/IPA, resolved dependency SBOM/CVE, secret scan a podpisů; false positives ověřit, reálné tajemství nikdy nepřidat do reportu. Doplnit privacy notice v bodě 5.

## Rozhodnutí a další postup

Žádné tvrzení o fyzicky ověřené bezpečnosti, právním schválení ani plné GDPR shodě. Žádný redesign, jazyková změna, merge, release nebo aplikace nových změn.
