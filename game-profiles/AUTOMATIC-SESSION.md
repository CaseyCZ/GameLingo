# Experimental automatic session reference
Joins the catalogue, scheduler, block tracker and snapshots without a native adapter. GTA VI and generic use one initial dialogue discovery area; phone/objective/help remain uncalibrated. Experimental catalogue entry is opt-in, not production-ready. Xbox and PS5 select the identical layout. The test feeds simulated OCR results, fingerprints, and translations; no external AI or actual remote-play input. Coordinates are crop-normalized LTRB converted to content-normalized LTRB. Successful but superseded reads are dropped; on rapidly changing backgrounds this can starve output and needs device-specific measurement. For failed translation attempts, unique request IDs and 500 ms backoff reject late completions from retries. This is not the user-facing GameLingo app, real UDP transport, automatic language identification, or a native build. Native adapters and UI still needed. Catalogue data embedded in the reference module is a snapshot; add generation or validation before runtime packaging.
