# GTA VI – shared experimental profile
One profile for Xbox Series X|S and PS5. The initial lower 35% search area is a generic discovery heuristic, NOT a measured GTA VI rectangle. Normalized LTRB coordinates refer to actual video content, excluding letterboxing. No fixed output rectangle. Phone, objectives and help remain uncalibrated. No runtime integration or public release until annotated actual gameplay from both consoles verifies layout, safe area variants, dialog detection, false positives and overlay geometry. Retain classic saved device profiles unchanged. The official PS5 gameplay showcase is a reference, not a verified source of burned-in gameplay subtitles. The pinned LiveDub multilingual GTA VI trailer is only an OCR smoke test: language changes, edited content and potential letterboxing make it unsuitable as release validation. No footage or audio committed. Raw is the intended default; paired outline OCR remains experimental comparison only. No Tesseract or external AI API.

## Offline calibration prototype
`calibrate.mjs` discovers candidate areas from temporally recurrent changing OCR lines and distinguishes spatially stable persistent labels. Uncertain tracks are not promoted. This is not a runtime rejection filter: a long static dialogue must not be hidden simply for persisting. The fixture anonymizes text as equality tokens, retains normalized geometry, and replays 30 raw frames per iOS engine from run 45775726680. Run `node test-calibrate.mjs`. Results refer to the encoded edited trailer; do not use them as console viewport coordinates. Thresholds are provisional, require unseen gameplay validation, and do not certify phone, objectives or help. Android raw lines were not available in job log; Android summary is not a geometry replay. No integration yet. The profile remains experimental and releaseReady false.
