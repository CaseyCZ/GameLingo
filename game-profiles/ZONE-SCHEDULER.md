# Multi-zone OCR scheduler (experimental)
One global active native OCR job, one latest frame descriptor, up to ten independent zone baselines. Native adapter must retain the latest frame buffer and the active job buffer; the scheduler itself stores only frame IDs and copied luminance signatures. Compare with last successful read, not skipped frames. Unknown fingerprint reads fail open. Provisional defaults: 100ms minimum interval per zone, 1000ms forced refresh, 250ms failure retry, 1500ms maximum result age. These are scheduling policies, not measured latencies or guaranteed deadlines. Oldest attempted eligible zone wins; priority breaks ties. Reset invalidates generation without releasing a running reader. Adapter must call finish when worker truly stops (including error), not merely on timeout. Superseded result is flagged; downstream must decide whether it is safe to display; not a subtitle lifecycle or translation implementation. Coordinates use normalized content LTRB, profile must be calibrated. No production code changes. Same signatures/geometry alone cannot establish semantic dialogue. Unit tests use simulated timing and fingerprints, not live OCR or device performance. Next: native adapters, multi-block tracking, stable ID and generation checked translation/overlay, hardware measurements.
